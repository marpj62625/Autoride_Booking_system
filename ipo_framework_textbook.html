CONCEPTUAL FRAMEWORK (IPO MODEL WITH FEEDBACK LOOP)

AutoRide Online Vehicle Booking & Fleet Management System with Cybernetic Closed-Loop Feedback

1. INPUT
Definition: Raw materials, data, resources, or requirements that enter a system to start a task.
A. User & Operational Requirements
  • Customer Credentials: Full name, contact number, email, and Google OAuth profile.
  • Digital KYC Documents: High-resolution photo uploads of Driver's License & Government IDs.
  • Booking Parameters: Vehicle model selection, pickup/drop-off schedule, and destination.
  • Financial Inputs: Downpayment or full payment amounts, GCash/Maya/Card payment details.
B. Hardware & Infrastructure
  • User smartphones (Android/iOS) and admin desktop/laptop dispatch workstations.
  • High-speed internet / Wi-Fi connection and vehicle GPS tracking hardware.
C. Business Policies & Rules
  • Daily vehicle rates, security deposit matrix, and double-booking conflict prevention rules.
Data Ingestion ➔
2. PROCESS
Definition: The transformation phase that converts your inputs into final deliverables using specialized development tools & engines.
A. System Development & UI Tools
  • HTML5 / CSS3 / ES6+ Responsive modern web interfaces & reactive DOM handling.
  • Leaflet.js & OpenStreetMap Interactive GPS maps, live location picking & fleet route tracking.
  • Capacitor & Android Studio Compilation of cross-platform native Android mobile APKs.
  • FontAwesome 6 Consistent visual icons, status indicators, and modal UI components.
B. Transformation Engines & Backend Logic
  • Python / Flask REST API Routing endpoints, session validation, and database operations.
  • Collision Detection Algorithm Algorithmic overlap checking that detects schedule conflicts and locks overlapping units.
  • Dynamic Balance Engine Instant computation of total prices, deposits, and remaining balances due.
  • Multi-Month Fleet Scheduler Interactive visual dispatch timeline managing vehicle availability.
C. Database, Cloud & Integration APIs
  • Supabase Cloud PostgreSQL Relational transactions, schema constraints, and Row Level Security.
  • Supabase Storage Encrypted cloud storage buckets for Driver's Licenses and receipts.
  • PayMongo API Automated e-wallet (GCash, Maya) and credit card payment processing.
  • Semaphore SMS & SMTP Email Real-time automated multi-channel customer dispatch alerts.
Generation ➔
3. OUTPUT
Definition: The final result or product generated by the transformation phase.
A. Operational & Customer Deliverables
  • Tamper-Proof KYC Profiles: Approved customer verification status with audit-ready driver records.
  • 100% Conflict-Free Bookings: Guaranteed reservations verified by real-time collision prevention.
  • Instant Digital E-Receipts: Automated booking vouchers with itemized pricing and payment references.
  • Automated Dispatch Notifications: Timely SMS and email reservation confirmations.
B. Administrative Deliverables
  • Centralized Fleet Dashboard: Live vehicle dispatching across Available, Reserved, and Maintenance states.
  • Financial Ledgers: Daily revenue aggregation, balance tracking, and Excel audit export.
C. System Deliverable
  • AutoRide System: Dual-platform vehicle rental and fleet management system (Web & Android).
4. FEEDBACK LOOP (Continuous Cybernetic Evaluation)
Definition & Feedback Function: The feedback loop acts as the self-regulating mechanism of the IPO framework. It continuously monitors and analyzes the Outputs, feeding real-time operational data and user evaluations back into the Inputs (to calibrate resources, requirements, and vehicle availability) and the Process (to optimize algorithms, software tools, and business rules).
A. Real-Time Operational Feedback
  • Instant Collision Warning: Immediate banner alert and button lock when overlapping dates are selected.
  • Dynamic Payment Sync: PayMongo webhooks instantly update booking status from Unpaid to Partially Paid or Paid.
  • Unsaved Changes Guard: Custom modal warning triggers when navigating away with unsaved booking edits.
B. Customer & Experience Feedback
  • User Ratings & Reviews: Post-rental customer reviews dynamically adjust unit satisfaction metrics.
  • Audit Trail Logging: Timestamped admin dispatch actions maintain operational accountability.
  • Dispute Resolution: Customer feedback informs refund policies and driver security deposit handling.
C. Maintenance & System Optimization
  • Vehicle Return Reports: Mileage, fuel, and inspection logs trigger maintenance states, updating Input inventory.
  • Completed Rental Release: Returned vehicles automatically transition back to Available for new inputs.
  • Telemetry & Error Logs: System performance monitoring feeds back into Process code updates.
🔄 Return Loop to INPUT: Inventory availability updates, revised customer KYC status, and adjusted booking rules. ⚡ Return Loop to PROCESS: Performance telemetry, algorithmic adjustments, and software feature refinements.
