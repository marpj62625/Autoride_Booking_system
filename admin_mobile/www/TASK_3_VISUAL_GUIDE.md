### Scenario B: No Profile Picture (Initials Placeholder)

```
???????????????
?             ?
?     JD      ?  ? User initials
?             ?     Generated from name
???????????????
```
- Background: Linear gradient (accent to purple)
- Text: White, 2.5rem, bold
- Initials: First letter of first name + first letter of last name
- Fallback: Single letter if only one name part

**Initials Generation Logic:**
```javascript
function getInitials(name) {
    if (!name) return 'U';
    const parts = name.trim().split(' ');
    if (parts.length === 1) {
        return parts[0].charAt(0).toUpperCase();
    }
    return (parts[0].charAt(0) + parts[parts.length - 1].charAt(0)).toUpperCase();
}
```
